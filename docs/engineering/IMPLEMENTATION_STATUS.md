# 实施状态

## 已实现且通过自动测试

- 日期和种子可复现的每日五柜生成。
- 三档起步、两档资产解锁和最多一个雾柜。
- 三层独立物品生成和雾柜单结果。
- 每日市场、定向商户、三名出场 NPC 与资金上限。
- 一次检查限制和公开/隐藏数据隔离。
- 三锤拍卖、玩家与 NPC 扣款、封槌同价处理。
- 玩家开柜、落败旁观、逐件立即出售或入库。
- 30–80 格仓库、同月补差价和跨月扣租。
- 发现图鉴、碎片持有、套装识别和软破产。
- 跨日刷新、NPC 现金延续和状态序列化。

## 已有交互样机但未接核心状态机

- 开柜拉闸、门体打开、逐层揭晓和重置体验。
- 当前根目录页面只演示这一段动作。

## 待实现

- 今日拍卖场与货柜切换正式界面。
- 检查选择和三锤拍卖正式界面。
- 核心状态机与根目录页面接线。
- 仓库、交易摊、藏品册和直播间页面。
- 正式 `localStorage` 存储适配、版本迁移和坏档恢复。
- 固定 NPC 好感、记仇、破产、复起和随机小传。
- 榜一、直播热度和直播定向买家事件。
- 发布包白名单脚本或人工打包流程。

## 开发优先级

1. 收敛运行时数据源。
2. 把每日生成器和状态机接入拍卖场 UI。
3. 完成一轮“选柜—检查—竞拍—开柜—处置”。
4. 接仓库与每日行情。
5. 再做 NPC 长线和直播随机事件。
