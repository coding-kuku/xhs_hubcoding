# 实施状态

## 当前可玩版本

根目录已经是完整离线小游戏，不再只是开仓动作样机。当前版本可以从每日拍卖场完整走通：

> 五柜比较 → 唯一检查 → 三锤竞拍 → 玩家或 NPC 结算 → 开柜/旁观 → 立即出售或入库 → 交易摊与藏品册 → 玩家主动进入下一天

## 已实现并通过自动测试

- 日期和种子可复现的每日五柜生成。
- 三档起步、两档资产解锁和最多一个雾柜。
- 普通柜三层独立生成，雾柜单结果且允许空箱负价值。
- 每日市场、定向商户、三名出场 NPC 与真实资金上限。
- 一次检查限制、公开/隐藏数据隔离和三锤拍卖。
- 玩家开柜、NPC 落槌后直接展示旁观结果。
- 普通柜安全封开门与雾柜断绳揭幕两套独立流程。
- 现代高级货品、车辆大奖、品相鉴定、本地图集和稀有结果展示。
- 逐件立即出售或入库，大件按实际格数占仓。
- 50–100 格仓库、同月补差价和跨月扣租。
- 发现图鉴、碎片持有、三套收藏识别和软破产委托。
- 玩家主动切日；提前收工需要确认，系统日期不会自动替玩家跳日。
- `localStorage` 存档、旧 30 格存档迁移和坏档恢复。
- 移动端竖屏 UI、触摸交互、离线合规和小于 10MB 的运行包。

## 已有基础但仍需深化

- 直播间目前提供热度、观众数与情境反馈，尚未形成完整随机事件池。
- 五名固定 NPC 已有资金、偏好、风格和跨日现金，但长期好感、记仇、破产复起与人物小传尚未接入。
- 收藏套装可以识别完成状态，剧情与完成奖励仍待确认。

## 下一阶段优先级

1. 固定 NPC 长线关系和低频随机事件。
2. 榜一、直播定向买家和收藏支线。
3. 继续扩充现代高级货品，同时控制素材与 ZIP 包体。
4. 将 JSON 基线与运行时常量收敛为单一数据源。
5. 完成最终移动端发布验收和版本标签。
