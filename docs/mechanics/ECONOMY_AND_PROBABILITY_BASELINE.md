# 经济、概率与商品价格基线 v3

状态：已实装。本文是唯一有效的经济设计文档；运行时以 `src/core/daily-generator.js` 和 `src/core/game-engine.js` 为准。

## 1. 核心规则

- 普通柜固定 3 个结果位，各自独立抽取类型、商品、数量和品相。
- 商品使用固定标准价；整柜价值由商品自然相加，禁止按预设盈亏反向缩放单品价格。
- 低价柜负责小额周转；档次越高，单柜亏损额、盈利额和方差越大。
- 普通柜盈亏标签在价值生成后判定，只用于结果展示和线索生成。
- `标准价`是应用数量、品相和销售系数前的价格锚点。

## 2. 价值公式与销售渠道

| 类型 | 中性价值 | 立即售价/清理费 |
|---|---|---|
| 普通货物 | 标准价 × 数量系数 × 品相系数 | 中性价值 × 当日普通货物行情 |
| 藏品/车辆 | 标准价 × 鉴定系数 | 中性价值 × 0.90 − 车辆运输费 |
| 碎片 | 标准价 × 品相系数 | 中性价值 × 0.84 |
| 垃圾 | 固定净处置价 | 等于固定净处置价 |

- 普通货物行情范围：`0.70–1.20`；每天 1–2 类上涨、1–2 类下跌。
- 藏品不参与普通货物行情。
- 定向商户溢价：常规售价 × `1.10–1.30`，单日收购 1–3 批。
- 负数售价表示必须支付清理费。

## 6. 雾柜

雾柜尚未改为固定单品价模型，继续使用独立结果倍率：

| 结果 | 概率 | 立即售价/参考价 | 中性价值/参考价 |
|---|---:|---:|---:|
| 空箱 | 14% | -0.12 | -0.12 |
| 近空 | 22% | 0.35 | 0.42 |
| 亏损 | 22% | 0.70 | 0.84 |
| 接近回本 | 18% | 1.00 | 1.08 |
| 盈利 | 15% | 1.60 | 1.85 |
| 大赚 | 7% | 3.00 | 3.40 |
| 爆仓 | 2% | 6.00 | 6.80 |

- 表中是基础倍率；普通货物结果再乘当日行情，车辆结果再扣运输费。
- 除第一个低价柜外，每个位置有 5% 替换概率；每日最多 1 个。
- 五柜初始版每日出现雾柜的理论概率约为 18.55%。

## 8. 调整边界与回归

- 调整平衡只能修改类型权重、候选池、数量/品相分布或拍卖价格带；不得缩放已生成单品价格。
- 本轮不新增商品、NPC 支线、榜一事件、套装剧情或奖励。

```bash
node tests/test-generator.js
node tests/economy-balance-test.js
node tests/mainline-playability-test.js
node tests/stress-test.js
```

运行时数值以 `src/core/daily-generator.js` 和 `src/core/game-engine.js` 为唯一实现；回归结果由上述测试直接验证，不维护平行的旧版配置或模拟器。
