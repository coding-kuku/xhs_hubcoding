# 货柜盲盒：线索系统 v1

## 一句话玩法

玩家先看货柜卡上的两条公开信息，再从“查单据、过磅、验箱门”中任选一次深入检查，然后决定是否进入三锤拍卖。

三种检查分别回答三个直观问题：

| 检查 | 玩家想知道什么 | 擅长发现 | 天然盲区 |
|---|---|---|---|
| 查单据 | 里面可能是什么？ | 品类是否集中、申报是否可信、是否多次转手 | 看不出当前品相和稀有度 |
| 过磅 | 里面可能有多少？ | 缺货、超重、重心、积水与近空箱 | 重物既可能值钱，也可能是废铁 |
| 验箱门 | 保存得怎么样？ | 干燥、霉变、包装、碰撞和水损 | 只能看到或闻到门口一小部分 |

整个检查只有一次点击，约 1.2 秒出结果，不增加清洁、找点或反复擦拭小游戏。

## 货柜卡怎么显示

拍卖场卡片保持短小，只显示：

> 旧港转运 · 申报：影像器材  
> 外观：箱底有浅水线

点进后出现三个按钮：

- 查单据｜更懂可能是什么
- 过磅｜更懂可能有多少
- 验箱门｜更懂保存得怎么样

检查结果仍然只用“观察 + 一句解释”：

> 过磅：比申报重 12%，重心居中。  
> 可能多装了货，也可能包含未申报金属件。

玩家无需记公式，也不会直接看到“好柜概率 63%”之类破坏盲盒感的数值。

## 公开申报的八种方向

| 申报方向 | 常见联想 | 可能的反转 |
|---|---|---|
| 旅店清仓物资 | 布草、灯具、餐具、旧陈设 | 发霉床垫或有价值的钥匙板 |
| 影像工作室器材 | 灯、脚架、线材、相机与录音设备 | 专业设备箱里只剩空盒 |
| 船厂维修备件 | 电机、铜线、轴承、航海件 | 超重可能只是废铁或压载块 |
| 巡演舞台物资 | 音箱、唱片、海报、灯牌 | 巨大但不值钱的残缺道具 |
| 文体用品库存 | 球拍、模型、玩具样机 | 大量单边或缺件库存 |
| 未分类私人旧物 | 藏品、纸品、碎片和异物 | 上限高，杂物与垃圾也更多 |
| 仓储退运杂货 | 普通商品、退运和残次品 | 申报太宽，几乎无法判断价值 |
| 旧港转运留置物 | 航海旧物、碎片与长期滞港货 | 年代感也可能只是受潮和积灰 |

这些文字是“单据声称”，不是系统承诺。它们通过箱内真实物品反向生成，但允许遗漏、混装与历史记录，从而形成可信的不确定性。

## 线索强度

内部用七档证据强度控制线索，不直接展示给玩家：强风险、明显风险、轻微风险、双向、轻微利好、明显利好、强利好。

典型例子：

| 结果 | 强度 | 合理判断 | 不能直接得出的结论 |
|---|---|---|---|
| 铅封完整，编号连贯 | 轻微利好 | 被翻找和调包概率较低 | 里面一定值钱 |
| 附有完整装箱数量 | 明显利好 | 缺件风险较低 | 品相一定完好 |
| 比申报轻 18% | 轻微风险 | 可能缺件 | 一定是空箱 |
| 明显超重 | 双向信息 | 金属或大量货物概率高 | 一定有铜或机器 |
| 探纸干燥、只有纸味 | 明显利好 | 保存风险较低 | 一定有藏品 |
| 探纸沾到黑色积水 | 强风险 | 水损和清理费风险很高 | 密封物或耐水金属必然报废 |

公开信息和一次深入检查合计最多形成中等优势。正面线索不能把“大赚”推成确定事件，负面线索也必须保留一种合理反转。

## 线索如何对应真实物品

系统顺序固定为：

1. 先生成并冻结三层物品、品相、数量和整柜价值档。
2. 从真实物品标签中挑选一个申报方向，再决定文件是准确、遗漏还是旧记录。
3. 根据真实重量、包装、积水和受损状态生成外观与检查结果。
4. 同一天刷新页面、退出重进或先看其他柜，都不会改变物品与线索。

这样不会出现“玩家出高价后系统临时换成垃圾”的作弊感。三层物品依旧各自按 35% 普通货物、35% 实体藏品、15% 碎片、15% 垃圾独立抽取；线索只是让观察到它的玩家更新判断。

## 防疲劳规则

- 每柜最多检查一次，不做连续搜证。
- 公开线索最多两条，单条不超过一行。
- 检查结果只呈现一个观察和一个解释。
- 首次教学默认推荐“验箱门”，让玩家先理解潮湿会带来真实亏损。
- 从第二个柜开始完全自由选择，不重复弹教学。
- 线索内容采用短片段组合，首版约 49 条基础文本即可形成数百种搭配，不显著增加离线包体。

## 与 NPC 的边界

物理线索永远真实；NPC 说的是个人判断、试探或谎话。玩家输掉拍卖后可以看到 NPC 的真实开柜结果，逐渐学习某个 NPC 是否擅长某类货物、是否爱虚张声势。这样长期角色关系会建立在可复盘的记忆上，而不是系统暗中读答案。

## 关联实现

这套线索已经接入 `src/core/daily-generator.js`：一次性生成当天五个货柜、雾柜替换、公开信息、三个可选检查结果、真实物品和 NPC 估价，并用固定日期与存档种子保证全天不变。
