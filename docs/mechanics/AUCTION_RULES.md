# 三锤拍卖机制 v1

## 目标

拍卖要制造“再跟一次还是收手”的压力，但不能让玩家通过连续输入 1 元加价，低成本试出 NPC 的精确底价。

## 玩家动作

每一锤只允许三个动作：

- 稳跟：使用该轮最低必要加价。
- 跳价：跨过更多加价单位，以更高成本施压。
- 放弃：退出当前货柜竞拍。

不提供自由金额输入，不允许无限连续出价。

## 三轮结构

| 轮次 | 名称 | 规则 |
|---|---|---|
| 第一锤 | 试探 | 基础加价，观察竞争者是否回应 |
| 第二锤 | 争夺 | 公开竞争的加价单位翻倍，犹豫成本上升 |
| 第三锤 | 封槌 | 玩家和剩余 NPC 提交最后报价并立即结算 |

基础加价单位随柜型增长：50、100、200、500、1,000。

## 同价与领先

- 封槌同价时，上一轮公开领先者获胜。
- 若并列者中没有上一轮领先者，使用当天已冻结的随机种子裁定。
- 刷新页面或退出重进不能改变裁定。

## NPC 公平边界

- NPC 只根据公开信息、自己的检查、偏好、情绪和现金估价。
- NPC 不读取真实物品或玩家私有检查。
- NPC 赢柜后立即扣款，处置后才回款；现金跨柜、跨日变化。
- 玩家落败可旁观 NPC 开柜，从结果中学习其判断风格。
