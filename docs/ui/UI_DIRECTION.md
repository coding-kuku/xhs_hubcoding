# 界面风格与交互方向

## 目标

视觉应当让人想到夜间港口、调度终端、旧物档案和潮湿金属，而不是网页弹窗广告、廉价赌场或堆满金色按钮的开箱页。

## 当前方向

- 竖屏优先，主要操作落在拇指舒适区。
- 深海青黑作为背景，青绿色用于状态和可操作项，低饱和金色用于价格与高价值提醒。
- 货柜与物品是视觉主角，装饰和边框保持克制。
- 信息层级先展示“这是哪个柜、要多少钱、我知道什么”，再给行动按钮。
- 开柜动作使用拉闸、解锁、门体位移、局部光线和结果卡反馈，不用夸张旋转抽奖盘。
- 动效服务于触感和揭晓，必须允许快速完成，避免每层强制长动画。

## 当前稿件

- `ui-style-v3.svg` / `ui-style-v3.png`：最新版方向参考，仍需结合用户反馈继续迭代。

- 根目录 `index.html`：当前完整可玩版本；历史交互样机保存在 `prototypes/archive/`。

## 页面清单

1. 今日拍卖场：资金、仓位、行情、五柜选择。
2. 货柜详情：申报、外观、一次检查、是否参拍。
3. 三锤拍卖：当前价、竞争者、稳跟、跳价、放弃。
4. 开柜舞台：逐层动作、结果价值与直播反馈。
5. 处置面板：立即卖、入库、清理费。
6. 仓库：批次、占位、行情、商户、扩租。
7. 交易摊：今日涨跌与快速出售。
8. 藏品册：实体藏品、碎片套装和发现记录。

## 前端验收

- 360–430px 宽度下不横向滚动。
- 不依赖 hover、键盘、全屏、传感器或剪贴板。
- 主要触摸目标至少约 44px。
- 重要文字不直接压在复杂图片上。
- 金额变化、亏损和清理费必须有明确正负反馈。
- 低端手机上动画不卡住主流程；尊重 `prefers-reduced-motion`。
