# 界面风格与交互方向

## 目标

视觉应当让人想到夜间港口、调度终端、旧物档案和潮湿金属，而不是网页弹窗广告、廉价赌场或堆满金色按钮的开箱页。

## 当前方向

- 竖屏优先，主要操作落在拇指舒适区。
- 深海青黑作为背景，青绿色用于状态和可操作项，低饱和金色用于价格与高价值提醒。
- 货柜与物品是视觉主角，装饰和边框保持克制。
- 信息层级先展示“这是哪个柜、要多少钱、我知道什么”，再给行动按钮。
- 交易摊不展示系统波动边界；每日行情先突出领涨、领跌，再用单行简报收纳其余类别。
- 可出售库存使用紧凑横向条目，价格与出售按钮固定在右侧，避免库存增长后产生冗长滚动。
- 藏品册只公开已经发现的碎片与套装名称，未发现内容统一用未知状态遮蔽。
- 发现记录按物品类型折叠收纳，默认只展开一个类别，避免记录增加后形成冗长瀑布流。
- 正文以 13–14px 为基准，辅助信息保持 10–12px；只有货柜贴纸等纯装饰文字允许更小。
- 页面纵向变长可以接受，不能为了一屏塞满信息而牺牲可读性。
- 开柜动作使用拉闸、解锁、门体位移、局部光线和结果卡反馈，不用夸张旋转抽奖盘。
- 动效服务于触感和揭晓，必须允许快速完成，避免每层强制长动画。

## 当前稿件

- `ui-style-v3.svg` / `ui-style-v3.png`：当前方向参考，仍需结合用户反馈继续迭代。
- 根目录 `index.html`：当前完整可玩版本，也是唯一交互实现。

## 页面清单

1. 今日拍卖场：资金、仓位、行情、五柜选择。
2. 货柜详情：申报、外观、一次检查、是否参拍。
3. 三锤拍卖：当前价、竞争者、稳跟、跳价、放弃。
4. 开柜舞台：逐层动作、结果价值与直播反馈。
5. 处置面板：立即卖、入库、清理费。
6. 仓库：批次、占位、行情、商户、扩租。
7. 交易摊：今日涨跌与快速出售。
8. 藏品册：实体藏品、碎片套装和发现记录。

## 前端验收

- 360–430px 宽度下不横向滚动。
- 不依赖 hover、键盘、全屏、传感器或剪贴板。
- 主要触摸目标至少约 44px。
- 正文、价格线索、操作说明和按钮不得使用 10px 以下字号。
- 重要文字不直接压在复杂图片上。
- 金额变化、亏损和清理费必须有明确正负反馈。
- 低端手机上动画不卡住主流程；尊重 `prefers-reduced-motion`。
