# 声音方向：舒缓手作声场

## 定位

声音服务于“慢慢拆开、擦净、发现好东西”的解压过程，而不是复刻嘈杂港口。主 BGM 《港口晨光》是原创的明亮田园游戏旋律，使用木琴感拨弦、暖色电钢和轻贝斯分层；不使用口琴、持续低频、空气噪声、唱片底噪或警报式信号。竞拍只轻微提升整体音量，不制造压迫感。

## 技术边界

- 不打包 `.mp3`、`.wav`、`.ogg`、`.m4a` 等音频文件。
- 使用原生 Web Audio 的振荡器、少量动作音滤波噪声和增益包络实时生成。
- 不使用第三方音频库、WASM、Worker、网络请求或动态执行代码。
- 首次触摸后才创建或恢复声音上下文；页面隐藏时暂停。
- Web Audio 不可用或启动失败时自动静音，游戏流程不得受影响。

## 状态结构

| 游戏状态 | 声音策略 |
|---|---|
| 拍卖场/交易摊 | 完整播放《港口晨光》，主旋律清晰可听 |
| 货柜详情 | 保留同一主题并退后音量，突出单据、过磅、箱门检查音效 |
| 第一锤 | 主题保持稳定，不加入鼓点或金属节拍 |
| 第二锤 | 轻微提升整体音量 |
| 第三锤 | 再提升少量音量，旋律和节拍不暗示货值 |
| 开柜 | 主题退后，以断绳、封签和钢门动作音为主 |
| 处置/仓库 | 主题低音量循环，出售、入仓和清理费使用不同反馈 |
| 藏品册 | 主题略微恢复明亮度；套装完成播放完整四音音效 |

## 听感红线

- BGM 不得循环播放噪声缓冲区。
- BGM 不得使用 100Hz 以下的持续无人机低频。
- 循环仅保留短暂呼吸，不再出现会被误判为静音的长留白。
- 不使用口琴式方波、窄带鼻音或持续单音主奏。
- 动作音可以保留纸张、绳索和箱门质感，但高频金属泛音需低通并压低音量。

## 公平性

- 拍卖音乐只读取当前页面和竞拍轮次，不读取隐藏货物、价值或 NPC 私有上限。
- 普通柜与雾柜在结果揭晓前都不能用声音暗示盈亏。
- 物品类型与稀有度音效只能在 `revealNext()` 返回公开结果后播放。
- 中标音只表示所有权，不表示柜内价值。

## 首版音效

- 货柜预览、选柜。
- 查单据、过磅、验箱门。
- 进入拍卖、稳跟、跳价、落败、中标、流拍。
- 雾柜断绳与揭幕、普通柜断封与开门。
- 普通货物、实体藏品、宝藏碎片、垃圾四类揭晓音。
- 出售、入仓、负价值清理、扩仓、临时委托、进入下一天。
- 四片碎片分别对应四个主题音，完成套装播放完整主题。

## 发布验收

1. 普通浏览器断网运行并完成一次完整拍卖与开柜。
2. 小红书 iOS 体验版验证首次触摸解锁、切后台暂停和恢复。
3. 小红书 Android 体验版重复同一检查。
4. 分别验证音乐开/音效关、音乐关/音效开和全部关闭。
5. 不支持 Web Audio 时确认设置显示降级提示，且主流程不报错。
