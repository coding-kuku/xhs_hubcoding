# 港口开仓：卡通 UI 概念方向

三套概念稿均以 `ui-style-v3.png` 为信息结构参考，只重做视觉语言，不改变主流程。生成方式为 Codex 内置 ImageGen。

## A：港口派对动画

高完成度竖屏手游 UI；明亮海港、圆润粗描边、二维赛璐璐质感；以水蓝、珊瑚橙、阳光黄和奶油白为主色。保留顶部资产、行情、五个货柜、选中货柜、线索、主按钮、直播条和底部导航。氛围轻快、社交、略带恶作剧感，但不复制任何现有游戏角色、图标或素材。

## B：玩具黏土码头

高完成度竖屏手游 UI；蓝调时刻港口微缩景观、黏土与软塑料玩具材质、凸起按钮与柔和阴影；以皇家蓝、海沫绿、橘色、奶油黄为主色。货柜作为视觉主角，原创海獭码头管理员只作为小面积引导角色。保留现有核心信息层级和触控布局。

## C：航海漫画贴纸

高完成度竖屏手游 UI；航海图纸、手绘漫画、剪纸卡片、胶带与运输标签，使用不规则墨线和受控网点纹理；以墨蓝、羊皮纸白、信号红、芥末黄、薄荷绿为主色。维持价格与主操作的最高视觉优先级，不使用赌场、转盘或复制角色。

## 共同约束

- 画布为单张 390×844 比例的完整移动端首页，不带手机外壳。
- 中文标签保持清晰、紧凑，避免无意义装饰文案。
- 交互需可落地：大触控区、清晰层级、选中态明显。
- 不复制《鹅鸭杀》或其他现有作品的角色、图标、界面资产与具体画风。
- 不使用赌场转盘、老虎机或廉价开箱页视觉。

## V2：去海报化

根据“画面太杂乱、像海报”的反馈，V2 将卡通表达限制在圆角、配色、图标和单一货柜插画中：80% 为标准产品 UI，20% 为卡通表现。

### V2-A：清爽亮色

暖白纯色背景、白色卡片、天蓝主按钮和珊瑚橙货柜；使用严格 8px 栅格、16px 页面边距和统一圆角。无港口场景、木牌、角色、绳索或贴纸装饰。

### V2-B：克制深色

深墨蓝纯色背景、统一深蓝卡片、青绿色主操作和琥珀色选中态；用间距和 1px 描边建立层级，保持低噪声。

### V2-C：柔和浅彩

浅海沫绿纯色背景、奶油色模块、深青文字、红色货柜和青绿主按钮；底部导航收纳在单一扁平卡片中，强调留白。

### V2 共同负面约束

不可生成场景式港口背景、大标题招牌、吉祥物、人物、海鸥、木质平台、绳索边框、纸张拼贴、贴纸堆叠、3D 微缩景观、超大 Logo、满版插画和无功能装饰标签。界面必须能明确拆分为 Header、Ticker、Tabs、Container Card、CTA、Live Row 和 Bottom Navigation。
