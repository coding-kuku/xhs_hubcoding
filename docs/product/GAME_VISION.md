# 游戏定位与体验支柱 v1

## 一句话定位

玩家在港口拍卖场根据不完整线索买下废弃货柜，用一次短促竞拍换取逐层揭晓的盲盒刺激，再通过收藏、行情和人物关系形成长期回访。

## 三个体验支柱

### 1. 未知揭晓

核心爽点是“下一层到底是什么”。普通柜三层独立抽取，允许连续出好货，也允许整柜都是垃圾；系统不在最后一层强行保底。

### 2. 有依据地冒险

玩家不是纯点抽卡。申报、外观和一次深入检查让玩家形成判断，但不会显示准确概率或答案。输赢必须能够复盘，不能让玩家怀疑系统在出价后换货。

### 3. 收集与长期记忆

实体藏品、宝藏碎片、发现图鉴和固定 NPC 让每次开柜留下痕迹。长期动力来自“还差一片”“这个奸商又来了”“今天有人高价收我的库存”，而不只来自资产数字增长。

## 节奏目标

- 首次进入到第一次开柜：30–45 秒。
- 看懂一张货柜卡：3 秒左右。
- 一次检查：一次点击，约 1.2 秒反馈。
- 一场拍卖：三锤完成，不使用自由金额输入。
- 开柜：一层一个明确动作和反馈，允许快速连续操作。

## 风险与公平

- 游戏必须有真实亏损，稳赚会快速消耗未知感。
- 正常判断是小幅正收益，无脑盲拍长期亏损，熟练经营拥有更高但受控的收益。
- 失败不能轻易死档；软破产只恢复继续参与低价局的能力，不抹去收藏和关系。
- NPC 不读取真实货物；所有当日内容在首次刷新时冻结。

## 主题气质

界面应像“夜港作业系统与收藏档案”，而不是网页广告、赌场老虎机或廉价开箱页。关键词：克制、潮湿、工业、档案感、局部高亮、明确触感。
