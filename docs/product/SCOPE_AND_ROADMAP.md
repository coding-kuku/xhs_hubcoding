# 范围与路线图

## 首个完整可玩版本

必须完成：

1. 每日五柜展示与档位解锁。
2. 公开线索、一次检查和参拍决策。
3. 三锤拍卖、NPC 出价和输赢旁观。
4. 普通柜三层与雾柜单结果揭晓。
5. 立即出售、垃圾清理费、收入仓库。
6. 每日行情、定向商户、50 格仓库和扩租。
7. 发现图鉴、碎片持有与套装识别。
8. `localStorage` 存档、跨日刷新和软破产。
9. 竖屏触摸体验和小红书离线自检。

## 第二阶段

- 固定 NPC 好感、记仇、破产、复起和人物小传。
- 直播间热度、榜一事件和定向买家。
- 收藏套装剧情与非数值奖励。
- 更丰富的柜型、检查文本、物品池和音效反馈。

## 暂不进入范围

- 登录、账号、云存档、在线排行榜。
- 多人竞拍、支付、广告、社交分享接口。
- AI 生成内容、远程配置和服务端活动。
- 强制体力、等待付费和真实货币经济。

## 里程碑

| 里程碑 | 验收标准 |
|---|---|
| M0 规则基线 | 经济、线索、生成器和状态机有文档及测试 |
| M1 主循环接线 | 从选柜到处置可在一个页面完整玩完 |
| M2 经营接线 | 仓库、行情、商户和跨月租金可玩 |
| M3 长线内容 | 图鉴、碎片和固定 NPC 关系可积累 |
| M4 发布候选 | 离线、移动端、包体和所有强制约束通过 |

当前已完成 M1、M2 与首版 M3 内容，进入 M4 发布候选阶段。
